# Sagar Singh — Portfolio Website

A responsive personal portfolio built with HTML5, CSS3 and vanilla JavaScript. It is designed to deploy directly to GitHub Pages without a build step.

## Project structure

```text
portfolio/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
├── assets/
│   ├── images/
│   │   └── profile.jpg
│   └── documents/
│       └── resume.pdf
└── README.md
```

## Run locally

Open `index.html` in a browser. No package installation or build process is required.

## Publish using GitHub Pages

1. Create a GitHub repository (for example, `portfolio`).
2. Upload the contents of this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.
6. Wait for GitHub Pages to publish the site and open the generated URL.

## Personalize before publishing

- Replace `assets/images/profile.jpg` with another portrait if desired, keeping the same filename.
- Replace `assets/documents/resume.pdf` when your CV is updated.
- Add verified project repository/demo links only when available.
- Add certificate issuing organizations or a LeetCode profile link only after confirming the details.
- The CV lists Chandauli as an education location; it is not presented as a confirmed current residence.

## Features

- Responsive desktop, tablet and mobile layout
- Mobile navigation menu
- Dark/light theme toggle with browser preference storage
- Scroll progress indicator and reveal-on-scroll effects
- Downloadable resume
- Email, phone, LinkedIn and GitHub links

Built with HTML, CSS and vanilla JavaScript.
